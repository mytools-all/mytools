> **本文回答**：参考哪些插件？保留哪些界面与交互？平台差异如何处理？

参考包仅用于研究界面与功能，不加载其 Electron preload，也不恢复 Rubick 兼容层。
工具遵循独立目录交付，系统访问经宿主能力与目录授权。界面按参考插件的工作流组织，适配窗口尺寸与明暗主题。

## 平台边界

- Windows 文件接收覆盖宿主与 WebView2 动态子窗口，显式在 UI 线程初始化 OLE 并维持接收器生命周期；仅处理系统 `CF_HDROP`，拖入反馈为复制。注册接收不授予插件文件权限，文件导入继续通过宿主拖放记录与能力授权。

- 主页插件卡片右键菜单提供打开、固定、添加 / 移除我的面板及移除最近记录；添加面板不直接打开插件。插件可通过 `hostSearch` 声明复用顶部搜索；文件搜索默认接入，分离窗口回退自己的搜索框。

- 我的面板中的插件项只引用插件 id 与功能 code，名称和图标实时读取插件信息，与主页使用相同的缺省图标。主页最近使用 / 固定收藏提供“添加到我的面板”，跨窗口共享入口列表，重复添加同一功能不产生副本。
- 添加入口表单提供“关闭添加”；Esc 先退出添加、再退出编辑，最后关闭面板。悬浮球复用 MyTools 图标，单击切换搜索窗口、右键打开我的面板；拖动捕获指针并保存位置，取消手势不启动搜索，小窗口下图形保持完整。
- 分离的开发者和偏好设置不显示页面级搜索框；已安装插件使用固定高度的搜索输入。授权管理按插件、具体能力或授权目录分组，支持插件显示名、标识、权限名及路径的组合搜索；撤销只针对所选插件与所选授权，失败时保留列表和错误提示。
- 原生拖放同时接入窗口与 WebView 事件；宿主先记录，再定向通知当前窗口。重复事件去重，插件仍通过 `fs.importdropped` 导入，不信任前端事件携带的路径。

- 我的面板参考 uTools 超级面板：全局鼠标中键在指针附近唤出独立网格窗口，支持插件功能、应用、文件 / 文件夹、http / https 网址；入口增删与顺序持久化；Esc / 失焦关闭，可恢复中键原有行为。插件仍由统一运行时承载。自动获取其他应用选中内容与上下文推荐另行扩展，不以剪贴板冒充当前选区。
- 搜索参考 rubick-everything 2.5.4 的过滤项、成对排序与日期筛选。允许保存自定义 Everything 条件，组合扩展名、排除项、修改日期范围；名称 / 路径 / 大小 / 扩展名 / 修改时间均有升降序。预览支持文本前 20KB、图片不超过 4MB、PDF / 音视频不超过 8MB；PDF 与媒体解码依赖 WebView2，其他格式使用默认程序打开。
- 重命名支持系统文件 / 文件夹拖入；导入能力仅消费当前窗口原生拖放记录。网络详情包括双栈地址、掩码、DNS、DHCP、MTU、速率与跃点，并保留完整 ipconfig /all 文本报告。

- 全盘文件搜索通过本机 Everything 1.4 / 1.5a 的 Unicode IPC 查询索引，不逐层扫描磁盘。索引访问为 exec 能力，首次需授权；内容预览还需独立授权，且只允许当前搜索结果中的文件。原 `fs.search` 保留为授权目录内的局部搜索与批量导入。
- 重命名处理同目录普通文件与文件夹；先验证整批输入，不覆盖既有文件。发生运行时错误停止后续操作并返回成功清单；撤销也受目录授权与冲突校验约束。不提供大小写单独改名或文件名循环交换；父文件夹与子项需分批操作。
- 剪贴板历史以宿主采集能力为准；文本可多选合并，图片仅在宿主提供记录时预览。文件拖出、自动粘贴到上一活动窗口不在当前能力范围内。
- Markdown 复用同系列开源编辑器；AI、公式与流程图没有伪装成可用按钮，数学与图表渲染仍有差异。笔记持久化在宿主存储，失败时保留编辑内容，导出使用系统保存对话框。
- JSON 过滤采用数据路径（属性、数组索引和通配符），不执行输入中的 JavaScript。Markdown 预览清洗 HTML，代码与文本转换均不执行用户输入。
- Ctool 交付上述核心工具，不以完整上游工具数量作为验收指标。正则测试在 Worker 中运行并设超时。
- OCR 使用讯飞印刷 / 手写文字识别 WebAPI（App ID / API Key），由宿主发送 HTTPS 请求；不内置公共账号。凭据默认仅驻留会话，用户明确选择后才写入本机插件存储；识别历史仅在会话中保留。真实识别需自备已开通对应服务的凭据。
- 工具导入支持浏览器 File API；Markdown 导出走宿主系统保存对话框；访问目录与批量操作走宿主能力。所有依赖本地携带，不依赖 CDN。

## 参考来源

参考包与各工具的 npm 链接由 `src/data/toolCatalog.ts` 维护。源码研究记录以以上版本为基线。
OCR 协议以 [讯飞手写识别 WebAPI 文档](https://www.xfyun.cn/doc/words/wordRecg/API.html) 与对应印刷识别服务契约为准。
第三方库与许可见 `各插件的 THIRD_PARTY.md`；参考插件没有明确许可的部分只研究交互，不复制代码或图标。
