# 备份、恢复与运行状态

偏好设置 → 备份与恢复位于快捷键之后、关于之前。

## 导出范围

| 范围 | 内容 |
| --- | --- |
| 所有用户数据 | 主程序配置、所有插件的数据与设置、剪贴板历史 |
| 仅 MyTools 配置 | 主题、快捷键、常驻选项、更新策略、面板入口、窗口位置及插件中心界面状态 |
| 所有插件的数据与设置 | 所有插件的共享存储命名空间、私有文件及启停状态 |
| 所选插件的数据与设置 | 仅所选插件的上述内容 |

插件设置与待办、识别历史等业务数据使用同一套存储，因此界面统一称“数据与设置”。插件程序默认不包含，可勾选同时备份以供离线恢复。没有备份程序时，清单中的插件身份与版本可用于重新安装。

ZIP 不包含日志、缓存、授权目录、权限许可、自启任务、登录凭据或 WebView 浏览器配置。插件自行写入宿主存储的数据按原样备份，可能含插件自己的敏感内容，请自行保管备份文件。外部 Umi-OCR 等服务的程序和配置不属于 MyTools 数据。

导出前保存并关闭插件。宿主阻止新插件会话及安装更新，等待已在执行的能力调用结束，落盘插件存储并通过 SQLite 在线备份接口生成一致快照。单个文件上限 128 MiB，解压总计上限 2 GiB，最多 50000 个文件；超过时明确失败，不输出半成品。

## 恢复流程

先选择 ZIP，只读预览备份时间、宿主版本和插件版本差异，再选择需要恢复的内容。确认对话框默认聚焦“取消”；选择覆盖并重启后，实际替换发生在下次启动初始化数据库、插件和设置之前。

所选项目采用替换语义，其他插件的命名空间、文件和启停状态保留。宿主保留本机插件目录，不恢复其他机器的授权及计划任务。离线插件程序需要身份、版本与宿主兼容性均通过检查。

恢复前在数据目录的 `backups` 中自动生成 `before-restore-*.zip`。替换使用同一磁盘上的暂存目录和事务记录；失败时回滚，异常退出后在下一次启动先完成回滚。不能完成回滚时停止初始化并保留现场。恢复结果会在主页提示，也可在备份与恢复页查看。不会自动删除安全备份。

ZIP 清单含 SHA-256 校验，用于发现损坏；不是数字签名，不能证明来源可信。读取时拒绝路径穿越、重复文件名、未知数据类型、符号链接和重解析点。来自更新宿主版本的备份需要先升级 MyTools。

## 日志与诊断

日志目录为 MyTools 数据目录下的 `logs`。操作日志按日记录启动、插件安装更新、启停、设置操作及备份恢复结果，保留最近 14 个日志文件；不记录用户正文或凭据。诊断 ZIP 只导出版本、系统与架构、插件数量和近期结构化操作，不打包原始运行日志与用户数据。

## 窗口与资源

主窗口、插件中心与独立插件分别记录位置、尺寸、缩放及最大化状态。显示器变化时将窗口移回可见区域。商店分类、搜索和滚动位置独立保存；不恢复未保存的编辑内容。

悬浮球和我的面板使用独立入口，不加载主页路由、商店与编辑器。重复启动仅唤起已有实例，自启重复触发保持后台。主窗口不可见时跳过界面健康轮询；主页和面板隐藏且没有插件会话超过 30 秒后，尝试使用 WebView2 休眠，打开时自动恢复。插件窗口和插件中心不休眠，插件编辑会话仍保留。此机制使用 [微软 WebView2 的 TrySuspend 接口](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_3)，不清空工作集，也不销毁页面。

内存对比应使用相同窗口、相同等待时间及同一统计口径。工作集包括共享页面，直接相加会重复计数；私有工作集更适合观察独占常驻内存。安装包大小不能推导运行内存，不以强制清空工作集作为优化。
